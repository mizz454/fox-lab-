FOX LAB — познавательный сайт

Внутри: index.html — готовый сайт с адаптивным дизайном, анимацией и интерактивной кнопкой фактов.

Как опубликовать на GitHub Pages:
1. Создай репозиторий на GitHub.
2. Загрузи в него файл index.html (можно также README.txt).
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку main и папку /(root), затем Save.
6. Подожди немного и открой ссылку, которую покажет GitHub Pages.
